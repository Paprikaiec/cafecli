# 折叠交给 Ctrl+O 全屏浏览层，默认流不再原地展开

ADR 0010 建立活动区合成器（单写者 `Display`），ADR 0011 定「Ctrl+O = 切换条带内最近可折叠块，Ctrl+T = 转写浏览层」。实测（v16.x）暴露根本矛盾：完成块一旦进入冻结回卷就无法原地再展开——`freezeSettled` 在答案开始的瞬间把思考 / 工具块提交为不可变回卷，等用户读到「🧠 思考 N 行 (ctrl+o to expand)」时它早已冻结，`toggleLastFoldable` 几乎永远回落到「Block frozen; view via Ctrl+T」，而且该提示还经 `printAbove` 落进回卷、层层堆叠。折叠头承诺了自己兑现不了的交互；活区尾 + 冻结的双重复杂度全为支撑一个实际不可用的原地折叠。

## 决策

**原地折叠取消，折叠只发生在 Ctrl+O 全屏浏览层。**

- **默认流 = 追加式回卷**。思考、工具调用渲染为**折叠单行头**（带块色条，无 emoji）；代码 / diff **内联**（默认前 100 行，超出标 `… +N 行 (ctrl+o 查看全部)`）；答案内联逐 token 流式。
- **Ctrl+O** 打开全屏浏览层，把最近五轮[[保留窗口]]的所有块**强制展开**渲染；再按一次 Ctrl+O / `q` / `ESC` 关闭、回到输入。浏览层与默认流复用同一套块渲染函数（`foldState=EXPANDED`），风格天然统一——浏览层只是流内容的展开。
- 浏览层**可滚动**：鼠标滚轮（SGR 1006）+ `j`/`k`/方向键（行）+ PgUp/PgDn（页）+ `g`/`G`（首尾）。
- **Ctrl+T 键位退役**，统一用 Ctrl+O；`/transcript` 命令保留为等价入口。
- **活区（live tail）收窄**为单写者最小重绘区：思考 spinner + 答案流式尾 + 审批卡。保留 `freezeSettled` 作为完成块进入追加式冻结回卷的提交边界；删除 `frozenFoldableAvailable` / 原地 `toggle` /「Block frozen」notice / `InlineRenderer.toggleLastBlock` / `RuntimeControl.TOGGLE_FOLDABLE`。展开态只在浏览层从保留窗口源块重建。

## 被否决的方案

- **延迟冻结最近块以支持原地展开**：回卷严格有序、追加式——答案在思考块下方持续提交回卷，思考块必须先冻结否则顺序错乱。要保留原地可展开就得整轮留活（不 drain 答案），直接违背 ADR 0010 的最小重绘区不变量、在无 DEC 2026 同步输出的终端（Terminal.app）撕裂。
- **完全删除活区 + 答案行缓冲**：spinner + 流式尾 + 审批卡仍需单写者重绘区；行缓冲让长段落只在模型吐换行时整段蹦出，牺牲逐 token 流畅，收益仅是少一个类。取 gut-and-keep-slim。
- **Ctrl+O 原地重打展开副本**：在回卷底部复制一份展开思考，噪音大，与「浏览层 = 流内容的展开」心智不一致。

## 后果

- ADR 0011「Ctrl+O = 切换条带内最近可折叠块」被本 ADR 取代；ADR 0010 的活区职责收窄为 [[活区尾]]。
- 折叠头不再印「ctrl+o to expand」式承诺文案；发现性靠浏览层与状态栏提示。
- `┌─ code` / `└─ end` 装饰行删除，代码块改用统一空行分隔；标题下划线 `====` / `----`、`---` 主题分隔线一并退役，全部改统一单空行。
- emoji 图标从工具 / 思考折叠头移除，仅保留[[块色条]]区分块类型。
- 代码 / diagram 行不再按终端宽 prose 折行，改按宽裁剪（尾 `…`），修复盒绘制流程图 / 树形结构错位。
- Ctrl+Y 补齐：状态栏早已宣传「Ctrl+Y」切换 HITL / YOLO，但从无绑定；补一个复用 `/hitl` 通路的切换。

## 修订

**A1（ADR 0017 D7）：「折叠头不再印『ctrl+o to expand』式承诺文案」这条后果撤销。** 禁令有一个具体理由
——`toggleLastFoldable` 承诺原地展开却几乎永远兑现不了，因为用户读到折叠头时块早已冻结。[[转写浏览层]]
**兑现得了**，所以禁的是「兑现不了的承诺」，不是「提及 ctrl+o」。`DiffBlock` / `CodeBlock` 的
`… +N 行 (ctrl+o 查看全部)` 其实从未遵守过这条，代码与本 ADR 一直无声矛盾；ADR 0017 把它扩到每个溢出的
工具结果，并把矛盾解掉。

**A2（ADR 0017 D5）：「运行中的工具块留在活区」不是本 ADR 否决的延迟冻结。** 这里被否决的是把**已完成**
的块按住不冻结，好让它能原地展开；ADR 0017 留在[[活区]]里的块**还没有结果**——它是瞬时内容待在瞬时内容
该待的地方，完成后照常提交，且从不在冻结之后改变。两者长得像，判别式是「这个块完成了没有」。

**A3（ADR 0017 D1）：默认流里工具调用不再只出一行折叠头。** 它出调用头（≤2 逻辑行 / 160 字符）加结果
预览（≤3 视觉行）；`execute_command` 运行期间另有一片共享 5 行的输出尾。思考仍然只出一行折叠头。
