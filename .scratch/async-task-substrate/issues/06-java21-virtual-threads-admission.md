# 06 — Java 21 + 虚拟线程 + 准入控制

Status: ready-for-agent
Type: AFK（⚠️ 运行环境下限抬升到 JRE 21）

## Parent

`.scratch/async-task-substrate/PRD.md`（决策见 ADR 0006）

## What to build

项目升级 Java 21（编译目标 + 运行前提）。每个[[任务]]（及其阻塞等待）跑在**虚拟线程**上。新增全局**准入控制**约束并发运行任务数：`深度上限`（限制 主→任务→子任务 派生层数，硬兜底）+ `等待即释放配额`（父任务前台等待子任务时释放自身准入名额，避免等待型死锁）。准入只管运行中任务；空闲留存（LRU）另行处理。

可演示/可验证：一棵深/宽的派生树无死锁跑完，峰值并发不超过上限。

## Acceptance criteria

- [ ] pom 编译目标 = 21；AGENTS.md/README 运行前提更新为 JRE 21
- [ ] 任务在虚拟线程上执行
- [ ] 准入控制为纯策略、可单测：深度上限被强制；父等待子时释放配额，证明无死锁
- [ ] 峰值并发运行任务 ≤ 配置上限（可经 `paicli.*` 属性配置，含合理默认）
- [ ] 测试：合成的派生/等待序列断言准入/拒绝 + 无死锁；`CountDownLatch` 峰值并发测试约束并行度
