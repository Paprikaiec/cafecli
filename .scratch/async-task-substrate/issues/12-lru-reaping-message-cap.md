# 12 — LRU 回收 + 消息镜像上限

Status: ready-for-agent
Type: AFK

## Parent

`.scratch/async-task-substrate/PRD.md`

## What to build

约束空闲任务的内存。保留最近活跃的 N 个空闲任务可续派（LRU，可配置，~5–10）；超出者淘汰最旧——被回收任务的 `task_id` 不再可续派（"已过期"），但保留一行结果摘要供 `/task` 历史。每个任务的 UI/transcript 消息镜像设上限（~50，可配置）。运行中任务由准入（#06）管，不归回收。

可演示：派生超过 N 个任务；最旧的空闲任务续派时变"已过期"，最近的仍可续派；每任务 transcript 内存有界。

## Acceptance criteria

- [ ] 超过 LRU 上限（可配置，默认 ~5–10）的空闲任务被回收：历史驱逐、续派返回"已过期"、保留一行结果摘要供 `/task`
- [ ] 每任务消息镜像设上限（可配置，默认 ~50），淘汰最旧
- [ ] 运行中任务不被回收（由准入 #06 管）
- [ ] 测试（纯）：喂空闲转换，断言到达上限时淘汰哪些任务；断言消息镜像在上限处封顶
