# 03 — 提交块重绘：暗色底纹 + 首行 `›` + 自换行

Status: ready-for-agent

## Parent

`.scratch/always-live-input-box/PRD.md`

## What to build

重绘用户提交后写回转写的那个块，让「我说的话」和「模型说的话」在回卷里一眼可分。

目标形态：整块铺一层暗色底纹并补齐到终端宽度；**只有首行**带一个暗色 `›` 标记；换行后的续行缩进对齐正文（不重复标记）。

三处与现状的差异：
1. 标记从每行重复的 `> ` 变成仅首行的 `›`；
2. 续行缩进对齐正文；
3. **块自己按终端宽度换行**——现状只按换行符切分，长单行靠终端自动折行，导致底纹在折行处断裂。换行必须是 wcwidth 感知的（复用 JLine 的列宽切分，不能用字符串长度），否则中日韩文本会算错。

配色分支复用行内 diff 已建立的 256 色 / 16 色能力探测：有 256 色走背景色，否则退化为前景色区分。

已知并接受：[[冻结回卷]]不重排，故窄化 resize 后旧提交块的底纹会出现参差半行——这是既有不变式的固有代价，不在本 issue 内解决。

本 issue **不改**编辑态标记（`* ` 的退役属于 09），只改提交后写回转写的那个块。

## Acceptance criteria

- [x] 提交块整行铺暗色底纹并补齐到终端宽度
- [x] `›` 标记只出现在首行；续行缩进对齐正文，不带标记
- [x] 超过终端宽度的单行由块自身换行，底纹在换行处连续不断裂
- [x] 含中日韩字符的输入换行位置正确（按列宽而非字符数）
- [x] 256 色终端走背景色，16 色终端退化为前景色且仍可读
- [x] 禁用 ANSI 时输出为可读纯文本，无残留转义序列
- [x] 空白 / 纯空格输入不产出空块
- [x] 单元测试覆盖上述各条（沿用现有块渲染测试的字节断言风格）
- [x] `mvn test -Pquick` 全绿
